# 📐 MathLab - 고교 수학 웹 애플리케이션 & 2026 9월 모의고사 퀴즈

고등학교 1, 2, 3학년 맞춤 수학 학습 및 **2026학년도 9월 전국연합학력평가 / 수능 9월 모의평가 기출 문제**를 반영한 인터랙티브 모의고사 퀴즈 웹앱입니다.

---

## 🌟 주요 기능

1. **스플래시 시작 화면 (Opening Intro)**
   - 앱 실행 시 정중앙에 대형 **`∑ MathLab (매쓰랩)`** 펄스 로고 전면 노출
   - 1.8초 동안 매쓰랩 브랜딩 & 로딩 게이지 애니메이션 재생 후 자동으로 로그인 창 전환
   - 기다림 없이 즉시 이동 가능한 [바로 로그인하기] 버튼 제공

2. **로그인 화면 (Login)**
   - 스플래시 직후 부드럽게 전환되는 모던 글래스 로그인 카드
   - 이름(닉네임)과 비밀번호 간편 입력 (이전 접속 닉네임 자동 완성)
   - Google 계정으로 로그인 버튼 (API 키 설정 연동)

3. **학년 선택 (고 1, 2, 3)**
   - **고등학교 1학년**: 공통수학 1·2 (다항식, 복소수, 항등식, 부등식, 순열과 조합)
   - **고등학교 2학년**: 수학 I·II (지수법칙, 함수의 극한 0/0꼴, 등비수열, 삼각함수)
   - **고등학교 3학년**: 수능 공통과목 (지수 계산, 미분계수의 정의, $\sum$ 시그마, 곱의 미분법, 접선의 방정식)

4. **실전 모의고사 퀴즈 & 쌍둥이 변형 문제 (Quiz & Variations)**
   - **실제 2026 9월 모의고사 문제 출제** (문항 번호, 배점, 출처 완벽 명시)
   - **KaTeX 수식 렌더링**: 수능 문제지 스타일의 미려하고 정확한 수식 표현
   - 5지선다 인터랙티브 보기 (① ~ ⑤)
   - **실시간 정답 확인 및 단계별 상세 해설(풀이 과정) 토글**
   - **🧬 쌍둥이 변형 문제 복습**: 오답을 단순 반복하는 대신, 틀린 문제의 핵심 개념을 적용한 유사 변형 문제 세트를 제공하여 완벽한 실력 완성 지원!

5. **📸 AI 사진 수학 문제 풀이 (Photo Math Solver)**
   - 모바일 카메라로 촬영하거나 PC에서 문제 캡처 이미지를 드래그 앤 드롭 업로드
   - Google Gemini 1.5 Flash Vision API가 이미지 속 수식과 문제를 자동 판독
   - 문제 조건 요약, 핵심 공식, 단계별 풀이, 최종 정답을 체계적으로 분석하여 제공

6. **💬 AI 수학 튜터 실시간 챗봇 (AI Math Tutor)**
   - 웹앱 어디서든 우측 하단 **[🤖 AI 수학 튜터]** 버튼으로 즉시 대화창 오픈
   - 퀵 칩(켤레복소수, 0/0 극한, 접선의 방정식, 지수부등식 등) 원클릭 질의
   - "이 공식 왜 써?", "다른 풀이법 알려줘" 등 질문 시 친절하고 정확한 수학 답변과 KaTeX 수식 풀이 실시간 응답

7. **API 키 관리 (아이피 키 직접 추가)**
   - 화면 우측 상단 [⚙️ API 키 설정] 모달에서 언제든 직접 Google Client ID 또는 Gemini API Key 등록 가능
   - API 키가 없어도 내장 시뮬레이션 및 데이터셋으로 모든 기능 즉시 체험 가능!

별도의 설치나 서버 실행 없이 바로 사용하실 수 있습니다:

1. 파일 탐색기에서 `c:\Users\USER\Downloads\hack` 폴더로 이동합니다.
2. [index.html](file:///c:/Users/USER/Downloads/hack/index.html) 파일을 더블 클릭하여 크롬(Chrome) 또는 엣지(Edge) 브라우저로 엽니다.
